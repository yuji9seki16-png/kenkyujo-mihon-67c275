PHILOSOPHY

なぜ、発酵と経営なのか

味噌は、素材を見極めて仕込むところから始まります。
ぬか床は、多様な菌が混ざり合いながら、１つの床を醸していきます。
米麹は、種菌から菌糸を張り胞子を飛ばし増えていきます。

経営にも、この3つの働きがいるのではないか。

仕仕込む　味噌のように

変わらず湧き続けるエネルギー源を持つこと。

醸醸す　ぬか床のように

異なる人たちが、個のまま切磋琢磨していくこと。

育育てる　麹のように

現場に合った仕組みをつくり、変え続けること。

ブランディングは、味噌づくりのように。
創業者・経営者が圧倒的な責任を持って言語化し、醸していく。

人材育成は、ぬか床のように。
マネジメント層を中心に、手間暇をかけ続けないといけない。

システム開発は、米麹のように。
関わるみんなで、担当者をハブに、必要な時に必要なものをつくる。

こうして、3つのサービスがそろいました。

02ぬか床

ぬか床的チームビルディング

カルテの実物を見る →

違う持ち味で、ひとつの床を醸す。

こんな時に
組織やチーム内の人間関係がうまくいっていないように感じる時。乾き過ぎてもウェット過ぎてもよくないもの。

共通の世界観の中で、多様な人材が多様なまま活躍できるような環境を整えます。
自律的にバランスを取ることがゴールです。

組織は、違う個性を持つ人たちが集まる生態系です。
全員が同じ考えになる必要はありません。
違いを知り、役割を引き受け、敬意を持って直接言い合える関係を、日々の手入れで育てます。

出来ること

  • 一人ひとりの強みの言語化
  • 相互理解研修、共通言語をつくる研修
  • 役割分担とチーム運営の設計
  • 対話・面談の仕組みづくり、査定制度を磨く
  • 組織の状態を観察し、手入れを続ける

原点
リクルートで25名の営業組織のマネージャーをしていた時のこと。切磋琢磨できる環境のはずが、足の引っ張り合いになっていました。役割分担を決めても不満が出て、共通の言葉を置いても一方的だと言われる。八方ふさがりの中で、メンバー全員を理解しようと、一人ひとりの強みを書き出し始めました。
強みは、裏を返せば弱みでもあります。上司と部下を超えてそれを分かち合ううちに、不満より前向きな提案が出るチームになり、売上も伸び続けました。この「助け合いの風土」が、ぬか床的チームビルディングの始まりです。

事例
社員約50名の会社で、心のカルテを12名分つくり、森のカルテへ。
中間・期末の面談に使う自己診断と上長評価のアプリも一緒につくりました。
アプリは2026年8月から社内で使われています。

03種

育てるシステム開発

8つの種と、動いている仕組みを見る →

自社でシステムを育て続ける。

こんな時に
世の中の買えるシステムが「高い、固い、むずい」と感じた時に。
既存のシステムも活用した上で、かゆいところに手が届かない時に。

顧客管理、受発注、経理、人材育成、情報共有。
担当者しか触れない。そんな仕組みを、現場の仕事を見るところから組み直します。
カモシカの現場で育ててきた仕組みを「種」にして、御社のAIへお渡しします。そこから先は、御社の現場で育ちます。

カモシカ氏は文系です。だからこそ「文系でも回せるか」を厳しく見ます。
…と言いつつ、もとはPwCコンサルティング（現IBM）のITコンサルタント。そこは、ご安心を♪

出来ること

  • 型化できているシステムの種
  • 自社に合わせた最適化・改善
  • 現場で直しメンテナンスする体制

半年で、社内に「仕組みをつくれる人」が1人育つ。
種を教材に、担当の方と一緒に、御社の現場の仕組みを育てます。
Seed　蒔く（1か月目）
種を選び、御社のパソコンで一度動くところまでをご一緒します。
Bloom　咲かせる（2〜5か月目）
月に一度、オンラインで2時間の伴走。担当の方が、自分の手で直していきます。
Harvest　実る（6か月目）
担当の方が、仕組みを1つ自分で直す・つくる。育て方を、御社の型として残します。
半年プログラム
種2つまで・月2時間の伴走×6回・合間のご質問（週1回まとめて文字で）・6か月目の型づくりを含みます。費用は、ご相談の内容をうかがってから、別にお見積もりします。

御社のデータは、カモシカ側には渡りません。取り組みそのものが、御社の資産になります。
※ AI（Claude Code か Codex）を事前に入れておいてください。

METHOD

経営を育てる5つの段

最初から完成形を決めません。まずは、よく見て、よく聞くところから。

  1. 観察する

    現場を訪ね、話を聞き、仕事の流れや人の関係を知ります。

  2. 源泉と課題を見つける

    大切にするものと、変えていくものを分けます。

  3. ともに仕込む

    言葉、関係、仕組みを、現場の人と一緒に設計します。

  4. 日々、手を入れる

    使い、試し、振り返りながら直します。

  5. 自ら育て続ける

    自分たちで判断し、変えていける状態を目指します。

3つ全部から始めなくて大丈夫です。いま必要なところから。
はじめのご相談は無料です。
お試しとして、ブランディングのご相談なら十字フレームの作成まで（目安1か月）、チームビルディングのご相談なら心のカルテ1名様分を、無料でおつくりします。育てるシステム開発には、無料のお試しはありません。

カモシカ氏

スーパー用務員／カモシカのコンサル 代表

経営も、ぬか床みたいに毎日かき混ぜてたら、ちょっと楽しくなるかも♪

2002年、PwCコンサルティング（現IBM BCS）に新卒入社。2005年、リクルートに入社。じゃらん、SUUMOで集客、ブランディング、営業、人材育成、組織マネジメントに携わる。リクルートでの16年で、200社以上のブランディングと集客、のべ500人以上の人材育成に関わる。男性で初めて4か月の育児休暇を取得。最大25名の営業組織のマネージャーとして、売上を前年比125％で伸ばし続ける。

2014年、妻・関恵とともに、京都・嵐山で発酵食堂カモシカを立ち上げる。2021年12月、リクルートを退社し、カモシカのコンサルを立ち上げる。
